---
description: 领取云桥配对码（异地网页端/手机 App 输码接入本机，20 分钟内有效）
---

为无法访问本机局域网的设备（公司电脑网页端、异地手机）领取云桥配对码。

1. 检查 relay 是否在运行：

```bash
curl -s -m 2 http://127.0.0.1:8787/health
```

无响应时先执行 `/cc-deck` 启动，再回来重试。

2. 领取配对码：

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/relay.mjs" --pair
```

3. 把输出的 6 位配对码**大字原样**展示给用户（等宽字体），并转述：

- 码 **20 分钟内有效、一次性**，请在远端设备尽快输入
- 异地网页端：浏览器打开 `https://cc.humumu.online`（或自建云桥域名），连接面板选「输配对码」输入 6 位码
- 手机 App：设置 → 新增服务器 → 配对码入口输入

4. 若提示「云桥未启用」：本机未设置 CCR_CLOUD_URL，输码配对用不上（LAN 扫码连接走 `/cc-deck` 即可）。

# cc-deck 旧版机制借鉴盘点

版本：2026-10-03

范围：只读对照 `web-console/index.html` 与 A 指挥桥现行规范/原型。本文不修改旧版，也不在本单改造 `005` 的输出物结构；“落地批”只冻结为下一批实施口径。

## 1. 结论先行

旧版真正成熟的是**信息压缩与来源上下文的处理方式**，不是旧版整体 IA。建议搬运“目录分组/折叠、文件类型与时间列、来源筛选、历史目录候选、待确认清单脱离消息流、远程产物下载兜底”等机制，改造后放回 A 指挥桥的会话详情、项目只读聚合和行动队列；不搬旧版以侧栏会话列表为中心的页面骨架、纯水位条、散落式悬浮层和运行时 inline 颜色。

## 2. 候选借鉴清单

## 3. 输出物落地批冻结口径

本批只冻结设计，不在本单改 `005`：

### 3.1 会话详情「输出物」Tab

- 顶部保留轻量摘要：`46 个文件 · 6 个目录`、是否截断、当前会话工作目录；不再重复项目总览的“输出物 46”指标卡。
- 分组规则：按文件相对 `cwd` 的父目录分组；同一目录至少 2 个文件才折叠成目录组；单文件目录项保持散文件行。组内按最近更新时间倒序，最近活跃组默认展开，其余默认收起；状态保存在当前会话内。
- 目录组头：文件夹图标、目录名、文件数、总大小/最近时间、组级主动作「批量下载」；行尾 `⋯` 提供展开/收起、打开目录（仅本机源）、复制路径。
- 文件行：类型图标、文件名、相对目录弱化段、大小、时间、删除/截断等异常徽标；出处引擎/源只在跨源模式需要时显示，不重复会话头部已有身份。
- 批量下载：第一期允许组内全选，不跨目录混选；点击后进入组级下载状态（排队、进行中、部分失败、完成），失败项可重试，命名冲突由下载器自动递增；移动端用 action sheet 选择“下载目录全部/单个文件”。

### 3.2 项目域「输出物」pane

- 项目页是只读聚合，按“源 → 项目目录”展示目录组，组内结构与会话 Tab 一致；每个组显示来源色、目录名、文件数和最近更新时间。
- 只提供“查看来源会话”“打开项目输出物”两类回原域入口；项目 pane 不直接写验收、不直接改文件，也不显示本机专属“打开目录”动作。
- 批量下载可以作为只读聚合的导出动作，但必须明确“从来源下载”，不改变项目状态；若来源不可达，显示逐源失败而不是把整个项目标红。

## 4. 明确不借鉴清单

1. **不搬旧版整体页面骨架**：旧版以左侧会话列表和单详情为中心，无法表达 005 已冻结的域栏/行动队列/主区/检查器四层，也会让团队、项目、设置再次退回“会话附属页”。
2. **不搬旧版普通上下文短条**：`ctxHtml()` 的阈值和 token 缩写可取，但普通水位条在新版会重新造成“汉字水位条/信息糙”的问题；完整展示统一由 `context-meter` 承担。
3. **不搬旧版 inline 源色与动态颜色字符串**：旧版 `srcBadgeHtml()` 直接把源色写进 `style`（`web-console/index.html:4465-4470`），不满足 005 的双主题 token、源色复用和浅色验收要求。
4. **不搬散落式悬浮层家族**：旧版同时有任务完成、撤销、USER_NOTE、待确认和服务器 popover；每个机制单看有效，合并会造成遮挡、焦点和优先级竞争。A 方向只保留一个行动优先层，非行动消息进 toast，需行动进队列/检查器。
5. **不搬右键作为主要入口**：桌面端文件行的右键可作快捷方式，但 005 必须把 `⋯` 和可见主动作放在行尾，手机不能依赖右键或 hover。
6. **不搬旧版“输出物开关关闭即隐藏 Tab”的可见性策略**：能力关闭时新版应保留明确的不可用/配置入口状态，不能让用户误以为功能不存在；设置与状态矩阵已有能力基线。
7. **不搬旧版输出物只收文档类的收录边界**：旧版 `artifactsTabHtml()` 明确只收文档、表格等交付物（`web-console/index.html:5763-5767`、`5827-5829`）；新版功能基线还包括图片/文件收发，需由类型 token和来源标识扩展，不可照搬“文档-only”。
8. **不搬旧版自动消失通知作为行动确认**：`USER_NOTE` 8 秒淡出适合非关键提示，不适合作为验收、接替、配对等需行动事件；这些必须有持久 badge 和可回看的处理记录。

## 5. 迁移验收口径

- 目录组、散文件、空态、加载态、部分失败、远程不可达都必须有真实可辨状态，不用 lorem ipsum 或假按钮。
- 批量下载必须有组级进度与部分失败重试，不以“点击后 toast 已下载”冒充完成。
- 会话 Tab 与项目 pane只读聚合的数据结构复用同一目录分组规则；写操作仍回原域。
- 深浅主题、桌面/手机、单源/多源聚合均复用同一组目录、引擎、源和状态 token；不在新输出物结构里写硬编码暗色。
- 交付前按 `specs/013-ui-design-playbook.md §9` 自检：不重复显示同一计数、每屏主动作明确、所有看似可点的目录组/下载/回来源控件均有真实状态。

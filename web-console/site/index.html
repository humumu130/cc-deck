WHY CC DECK

离开电脑，会话不掉线

在 PC 端装一个插件，Claude Code 的会话就实时同步到随身设备。适合把 Claude Code 当主力工作流、离开电脑也不想掉线的开发者。

随身掌控会话

多会话四态速览，上下文水位三端同色；权限审批与提问远程点选，发消息、传图片、切换模型，随时打断或续聊。

HOW IT WORKS

三步接入，端到端加密

01

PC 侧启用 relay

两种方式任选其一：

① Claude Code 插件——安装后重启 Claude Code，执行 /cc-deck，relay 后台即起：

claude plugin marketplace add humumu130/cc-deck claude plugin install cc-deck@cc-deck-plugins

② 桌面端 EXE——已内置 relay，下载安装即用。

02

扫码配对

同网 App 直接扫终端二维码即连。
跨网在面板一键领取 6 位配对码，输入即连。

或 841609
03

随身掌控

审批、注入、模型切换随身同步；任务完成后主动推送到手机与手表。

远程审批消息注入模型切换完成推送

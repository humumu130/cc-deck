8三层入口，第 0 层零配置

设置已三段式嵌入主窗口（桌面 rail ⚙ · 设置导航 · 内容；手机 = 底部 Tab ⚙，浏览态）。第 0 层默认继承本机环境（ANTHROPIC_BASE_URL / ANTHROPIC_AUTH_TOKEN 原样生效）——单厂商用户永远碰不到这页，什么都不用填，这也是信任基线。M1 手编文件，M2 才有这页 UI，且它只是 providers.json 的编辑器，不是新存储——电脑/网页表单写的是同一份文件；手机 App 只浏览、验证、换路由（录入回电脑：手机是指挥台，不是安装器）。

9凭证不出本机

UI 只显尾 4 位；「验证连通」由 relay 从本机直连厂商发起；端上拿到的是无 token 字段的脱敏视图——payload 里没有 token 字段是数据结构事实，不是 UI 遮盖。输入通道走既有鉴权信道（LAN token / 云 E2E），与云桥 token 下发同一信任级。

10给多疑者明路 + 默认表可改

不愿在 App 里输 key？手编文件与 $ENV_VAR 引用档两条替代路径在设置页常驻明示——给明路比说服有效。角色路由默认表（Leader 强模型 · 开发便宜档 · 验收换厂商 = 认知独立 · 调研最便宜）只是初始映射，开团时逐成员可改。

🔌 异构模型：每个成员可绑不同厂商的模型（编制卡上选型，凭证只存 relay 本地、永不下发端上）。默认路由：Leader 强模型 · worker 走包月便宜档 · 验收换厂商——流程独立之外再加认知独立（同厂商模型会犯一样的错）。换模型 = 同一套接替机制（板 + git 是记忆，transcript 是消耗品）：池烧穿或限流时，同身份换个模型重 spawn 即继续。

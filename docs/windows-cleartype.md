# Windows 字体发糊/锯齿：三层自查向导（2K 屏适用）

> 背景：CC Deck 桌面版（Tauri/WebView2）在高分屏 Windows 上字体边缘发毛。经查**应用侧 DPI 感知已正确声明**（安装包 manifest 实测 `PerMonitorV2`），发糊主要来自 Windows 显示设置的**分数缩放**与 ClearType 校准状态。本向导按性价比排序，前两步免费、第三步系统级。

## 第一步：确认缩放档（最常见根因）

2K 屏（2560×1440）Windows 默认推荐 **125% 或 150% 缩放**——这是「分数缩放」，Windows 应用（含 Chrome/Edge/CC Deck）在此档位会把 ClearType 彩色子像素抗锯齿**退化为灰度抗锯齿**，小号灰字（如界面里的次要说明文字）边缘发毛是这一档的固有观感（同屏 Chrome 网页小字同样发毛，可对照验证）。

**缓解选项（按接受度选一）**：
- **缩放调 100%**（2K 屏 100% 字会小——配合 CC Deck 设置 → 通用 → 界面字号调「大/特大」档，字号放大走应用层渲染，不糊）
- 缩放调 **200%**（整数倍=恢复彩色子像素 AA，但 2K 屏 200% 等效 1280×720 太大，一般不选；4K 屏选这个正好）
- 维持 125%/150% + 走第二步校准（减轻但不根除）

设置路径：`设置 → 系统 → 屏幕 → 缩放`（改后注销重登生效最稳）。

## 第二步：ClearType 校准（免费，五分钟）

Windows 自带的字体渲染校准器，按提示选「看起来最清晰的文本样例」：

1. 按 `Win` 键搜索 **「调整 ClearType 文本」**（或控制面板 → 显示 → 调整 ClearType 文本）
2. 勾选「启用 ClearType」→ 下一步
3. 四轮样例选择（每轮挑最清晰的一块）→ 完成

多数显示器出厂状态下校准一次即有可见改善（尤其副屏/拼接屏每台都要过一遍——向导会对每个显示器各出一轮）。

## 第三步：显示器原生分辨率核查（如果还有糊）

`设置 → 系统 → 屏幕 → 显示器分辨率` 应为面板**原生分辨率**（2K 屏=2560×1440）。若被设成 1920×1080 等非原生档，GPU 整图缩放=全局发糊（不止字体）。

## 应用侧已做/不做的事（对照）

| 项 | 状态 |
|---|---|
| DPI 感知 | ✅ 安装包 manifest 实测 `PerMonitorV2`（系统按显示器逐台正确缩放） |
| 网页缩放（Ctrl+滚轮） | 🚫 壳内已停用——分数 zoom 叠分数 DPI 是双重糊源；字号请走 设置 → 通用 → 界面字号 |
| 渲染开关 | 保持 Chromium 默认（ClearType 全开）；无 disable-lcd-text 之类负优化项 |
| 字体栈 | Segoe UI/微软雅黑系统字体直用（系统渲染管线，无自托管形变） |

## 仍不满意时反馈口径

以上三步过完仍觉得糊，请把以下信息带给开发者（截图 + 数字）：
1. `设置 → 系统 → 屏幕` 的缩放百分比与分辨率截图
2. CC Deck 关于页的**「渲染环境」行**（版本行下方——直接显示 `缩放 150%（DPR 1.50 · 分数档=文字子像素 AA 关闭…）` 这样的判定，报出来即完成归因：分数档=本向导路径坐实；整数档=另有因，转开发者排查）
3. 同屏 Chrome/Edge 打开任意网页小字是否同样发毛（区分应用内 vs 系统级）

- **影响面**：不动＝README 与现实继续分叉，P1-7 开源就绪面无法定稿（两版 README 大纲已备、条件于此，见 `open-source-readiness-p1-7.md` §一）；动了＝README 按开源定位重写、端矩阵宣传收敛、P1-2/P1-6/P1-7 外部前置件新增一批投入。

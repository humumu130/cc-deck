重设计方案（蓝标对应下方决策清单）

决策清单（逐条拍板，可只否决其中几条）

  1. 1头部减重 + 图标钮去边框：Logo 42→36；扫码钮、配对刷新钮、区头问号三枚「静默图标钮」统一去描边（tintSoft 底无边框）——与会话页返回钮、思考开关同一体系。
  2. 2区头去字符图标 + 选中卡改色：◫⇄≡ⓘ 四个胖瘦不一的字符图标全部移除，区头纯文字（11px 加宽字距）；选中服务器卡从绿框绿底改为「品牌蓝框 + 选中蓝底」，与全 App 选中语言统一——绿色从此只表示「在线插头」；身份色从 7dp 圆点改为卡片左缘 3dp 色条（名称不再被点隔断、右侧不再显空）。
  3. 3「＋手动添加」改虚线幽灵卡：从右下角孤悬蓝字链接改为与服务器卡同宽的虚线占位卡（40 高、灰字）——列表区的「可添加」语义更直观，少一处游离的强调蓝。
  4. 4后台保活卡瘦身 78→56dp（最丑的一块）：修复黑色边框 bug（代码里写了 borderWidth 没写 borderColor，RN 默认纯黑——你截图里那个刺眼黑框就是它）；挤排改两行：标题行右端「去优化 ›」蓝色文字链，副行整宽一句话「断线频发？授予系统级后台豁免」——文字永不截断，黄色只留 7dp 状态点。完整说明仍在添加连接页。
  5. 5配对码降权：19px→15px 等宽数字（层级靠字重+等宽+字距，不靠尺寸）；倒计时/刷新钮与码严格同一行垂直居中。
  6. 6显示区节奏：默认改折叠（你设过一次就不动了；已保存的偏好不受影响）——mockup 画的是展开态；行图标换 12px 细线 SVG（消息泡/半月/回车箭头，胖瘦一致）；拨杆轨道去边框。
  7. 7空闲变灰行拆两行 + 开关实色：输入框（56→52）+「分钟」独占第一行右侧，「负数 = 永不变灰」降为第二行注脚——永不截断；回车发送开关从半透明淡蓝改品牌蓝实色（与思考开关同语言）。
  8. 8关于区并两行：「检查更新」行从抽屉移除——功能不砍，并入「版本」行点开的弹窗里（那里本来就有一个同款「↻ 检查更新」按钮，两处重复）；抽屉只留 版本 / 反馈 两行。底部补安全距离（现状会贴到手势条）。
顺带答复你之前问的：会话页左上角返回按钮要不要边框？
结论：不加边框，维持现状。 它代码上本来就没有边框——你看到的「边框感」是 tintSoft 半透明底色与背景的填充边界。加描边会在 26px 小钮上形成「填充边界+描边」双边缘，更糊更重；去掉底色则丢失落点感、也和同一行的「思考」开关不成对（两者现在同为 tintSoft 底，视觉上已经是一对）。真正要修的是反向的：把抽屉里那三枚带边框的图标钮（扫码/刷新/问号）的边框拆掉，向返回钮看齐——这正是决策 ①。 ← 返回钮现状（放大），无需改动。

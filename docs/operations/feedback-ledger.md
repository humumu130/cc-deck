# 用户反馈闭环台账

> 定位：每条用户反馈一行的**唯一闭环账本**（flow-hardening 环 10 硬闸）。
> 没有「留装机复验」式黑洞——每一行要么走到「用户已确认」，要么显式停在中间态被看见。
> 维护规则：反馈到达即入行（环 1-2）；修完翻「已修待验」并挂验收单行号；回填后按 ✓/✗/未测三态收口（✗ 开修复单重入一行）。台账里任何一行停在「已修待验」超过一个发版周期 = 主动追问，不许沉默搁置。

## 记录格式

| 列 | 含义 |
|---|---|
| 日期 | 反馈到达日 |
| 原文摘要 | 用户原话关键句（不转译，长文截 40 字） |
| 任务号 | 任务单编号；批内件用 #NN-件N |
| 分支/提交 | 工作线与落库提交（squash 笔） |
| 验证方式 | L1 机器 / L2 CDP+截图 / L3 装机 / L4 真机（分级定义见 [flow-hardening.md §2](flow-hardening.md)） |
| 状态 | 处理中 / 已修待验 / 用户已确认 / 真机待验 / 已否决（含理由） |

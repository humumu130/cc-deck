# 手机端权限模式切换 · 重设计（只设计，未实现）

> 2026-09-19 ｜ 5.3 Flash 视觉子 Agent 产出 ｜ mockup：[perm-mode-mockup.html](perm-mode-mockup.html)（360dp 视口，8 帧）｜ 过审截图：`perm-mode-mockup.png`
>
> 用户原始诉求：权限切换按钮放在 tab 栏下面"有点突兀"，重新设计；建议考虑会话页 Head 上（可缩小/变形），也允许更好的自拟方案。

## 1. 现状（DetailScreen.tsx 核实）

- `PERM_CYCLE = [default, acceptEdits, plan, bypassPermissions]`，`PERM_LABEL` = 标准/自动编辑/规划/跳过。
- 渲染在 tab 行下方 `subFilterRow` 独占一行，一个 `filterChip` 胶囊（px10/pv4/r10，tintSoft 底 + line 描边；点亮 tintStrong 底 + brandA@0.4 描边），文字 `权限·{label}` 11px，点击循环切下一档，发 `COMMAND_PERM`。
- 三处问题：
  1. **独占一行**：一个低频控件占掉 tab 行与内容间约 36px 竖向空间（chip 26 + marginBottom 10），视觉上孤立突兀；
  2. **盲循环**：四档循环最多 3 击才到目标档，途中档位不可见、语义不可见；
  3. **危险档无警示**：跳过（bypassPermissions，免审执行一切命令）点亮态与普通档同为品牌蓝，从标准 3 连击误触即达，无任何确认。

## 2. 四档语义与展示策略

| 档位 | 值 | 胶囊态 | 依据 |
|---|---|---|---|
| 标准 | `default` | 幽灵态（仅盾图标） | 默认态低噪声，但保留锚点保可发现性 |
| 自动编辑 | `acceptEdits` | 点亮信息态（品牌蓝）+ 短标签「自动」 | 非默认即常显；短标签控宽 |
| 规划 | `plan` | 点亮信息态 + 「规划」 | 同上 |
| 跳过 | `bypassPermissions` | 警示态（waiting 红）+ 「跳过」+ 盾内感叹号 | 危险档全时醒目，见 §6 |

短标签口径：胶囊上仅 `自动/规划/跳过` 两字短标签，全称与解释文案只在四选一面板出现——胶囊是"状态灯"，面板是"说明书"。

## 3. 候选方案对比

| 方案 | 位置/形态 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. Head R2 设置簇 + 底部四选一面板** | R2 元信息行最右，思考开关左侧，与思考开关同形态语言（14px 高小胶囊）；点击弹面板 | 省 36px 竖向；与"思考"构成会话级设置簇语义自然；危险档常显于视口顶（读转录时也可见）；面板直选+确认解决盲循环 | R2 更挤（有预算，见 §5）；14px 触点小（hitSlop 补偿，与思考开关同口径） | **推荐** |
| B. 并入 tab 行右端 chip | tab 行尾部加图标 chip | 不加行、可发现 | 破坏 tab 等宽指示条几何（`tabInd` 依赖 tabWrap 宽度自算）；导航与控制混杂；横滑切页易误触 | 否 |
| C. 命令栏内图标 | 底部输入栏尾部 | 与"即将发送"上下文相关 | 权限是会话级持续状态不是逐条消息属性；被键盘遮挡、读转录时不可见——**危险档必须常显于视口顶**，此方案违背 | 否 |
| D. 思考+权限合并进齿轮菜单 | R2 只放一个齿轮 | 空间最省 | 藏掉用户已拍板的思考快开关；高频动作多一层；两控件形态被强统一 | 否 |
| E. 保留循环、仅挪进 Head | 同 A 位置但点击仍循环 | 改动最小 | 不解决盲循环与危险档无确认——位置只是问题的一半 | 否 |

A 的核心论据：**bypassPermissions 是"不系安全带开车"态，必须 ambient 常显在屏幕顶部**，所以 Head 位置不只是省空间，而是危险档可视性的正确锚点；思考开关（同为会话级、同 14px 胶囊）在旁边，天然成组。

## 4. 推荐方案规格（样式值级）

### 4.1 Head 胶囊（替代 subFilterRow，删除整行）

锚点：`headMeta` 行内、思考开关左侧；`cluster` 容器 `marginLeft:auto` 右锚，簇内 gap 6。Pill 与思考开关共用形态语言（h14/r7/tintSoft 底）。

| 态 | 尺寸 | 底 | 描边 | 内容 | 文字 |
|---|---|---|---|---|---|
| 幽灵（标准） | 20×14，r7，px0 居中 | `tintSoft` | 1px `line` | 10px 盾形描线图标（stroke 2.4，色 `dim`） | 无 |
| 点亮（自动/规划） | h14，r7，px6 | `tintStrong` | 1px `withA(brandA,0.4)` | 盾图标 + gap4 + 短标签 | 9px/600 `brandA` |
| 警示（跳过） | h14，r7，px6 | `withA(waiting,0.10)` | 1px `withA(waiting,0.45)` | 盾+感叹号图标 + 「跳过」 | 9px/600 `waiting` |

- 浅色值：brandA `#2F7FE8`、waiting `#DC2626`、tintSoft `rgba(47,127,232,0.06)`、tintStrong `rgba(47,127,232,0.13)`、line `rgba(52,58,50,0.13)`、dim `#5D665C`（theme.ts LIGHT）。
- 深色值：brandA `#4D9FFF`、waiting `#F0524F`、警示底 `withA(#F0524F,0.12)`、描边 `withA(#F0524F,0.5)`、tintStrong `rgba(93,134,245,0.16)`；幽灵态描边提亮为 `rgba(125,165,220,0.22)`（深色 line 0.10 太弱，自审结论）。
- 图标：react-native-svg，viewBox 24，盾 `M12 3l7 3v5c0 4.5-3 7.5-7 9-4-1.5-7-4.5-7-9V6l7-3z`；警示态追加 `M12 9v4` + 底部点。
- 触达：`hitSlop {top:8,bottom:8,left:6,right:6}`（思考开关为 6，此钮更小再补 2）；`accessibilityLabel: "权限模式：{全称}，点按切换"`。
- 9px 字号说明：与用户拍板的思考开关文字（thinkToggleT fontSize 9）同口径，保设置簇一致；可读性由面板内 13px 全称兜底。

### 4.2 四选一底部面板（替代循环点击）

- 触发：点胶囊任意态。 scrim `rgba(8,12,18,0.38)`；面板贴底，bg `panel`，顶角 r14，描边 `line`，px14 pt6 pb14，顶部 36×4 r2 抓手条。
- 标题行：`权限模式` 13px/600 text + 右侧 ✕（faint）。
- 四行，行高 ~38（pv9 ph8，r10）：
  - 名称 13px/600 text；描述 10px dim（文案见下表）；
  - **当前项**：整行 `tintStrong` 底 + 右缘 ✓ brandA（选中靠底色，不靠游离符号——自审结论）；
  - 跳过行：名称 `waiting` 色 + 「危险」badge（9px，r4，px4，`withA(waiting,0.10)` 底 + 0.45 描边）。
- 行文案（与 PERM_LABEL 全称一致）：
  | 名称 | 描述 |
  |---|---|
  | 标准 | 每个命令与文件编辑都需确认 |
  | 自动编辑 | 文件编辑免审，命令仍需确认 |
  | 规划 | 只读规划，先出方案再执行 |
  | 跳过（危险） | 所有命令与编辑免审直接执行 |
- 点选非危险档：即发 `COMMAND_PERM` 并收起面板（2 击直达任意档）。
- **跳过二次确认**：首击不生效，该行红 tint 选中 + 面板底部展开整宽确认区（见 4.3）；再击「确认跳过」才发命令。

### 4.3 危险确认区（面板底部整宽）

- 容器：`withA(waiting,0.06)` 底 + `withA(waiting,0.3)` 描边 + **左缘 3px `withA(waiting,0.55)` 强调条**（视觉上从属跳过行，自审结论），r10，p10，mt6。
- 文案 10.5px/14 `waiting`：「开启后所有命令与文件编辑将不经你确认直接执行，仅在你完全信任当前任务时使用」。
- 按钮行 mt8 gap8：`取消`（flex1/h32/r8/panel2 底+line 描边/dim 12px）｜`确认跳过`（flex1/h32/r8/**waiting 实底**/白字 12px/600）。
- 关闭路径：取消、scrim、✕ 均收起不发命令。

### 4.4 循环 vs 面板论证

| 维度 | 循环（现状） | 面板（推荐） |
|---|---|---|
| 到达目标档 | 平均 2 击、最多 3 击盲选 | 恒定 2 击，选项全可见 |
| 档位语义 | 不可见 | 每档一句描述，首次使用即懂 |
| 误入危险档 | 3 连击即达、无确认 | 需两击 + 确认按钮，误触不可达 |
| 长按出面板（第三选项） | — | 不可发现，弃 |

## 5. R2 空间预算（360dp 最坏情况）

可用宽 = 360 − px24（head）− back26 − gap8 = 302px。点亮态最宽组合：时长 ~34 + ctx 组 ~62（label8+bar30+pct24）+ 跳过胶囊 ~44 + 自动胶囊 ~54 + 思考 ~52 + 簇内 gap ~12 ≈ 258 → 源名剩 ~44px 截断（`numberOfLines=1` 已有）；幽灵态时源名 ~118px。短标签「自动」（替代"自动编辑"全称）正是为把最坏档从 72px 压到 54px（自审 P1-4 修复）。结论：可接受，源名本就是 R2 里优先级最低的可缩项。

## 6. 危险档警示设计（为什么这些选择）

- 用 `waiting`（浅 `#DC2626`）不用 `error #C2410C`：error 是"已出错"，waiting 是"需注意"，与既有 `stripBtnWarn` 用 `withA(waiting,0.3)` 描边的先例同语义。
- 双编码（色弱可达）：红之外，警示态图标为**盾+感叹号**、面板行有「危险」badge——形状+文字与颜色三重编码，红蓝色盲可区分（自审 P1-5 结论）。
- 常显原则：警示胶囊驻留 Head，读转录、切 tab 时都在视口内；不做成一次性 toast。
- 红饱和度刻意止步 tint+描边+文字，不用实底——实底会把 14px 胶囊变成整行最重元素，压过标题（自审复审意见：勿再加深）。

## 7. 深色版

同构映射 DARK token（见 §4.1 深色行）。两处专属调整：幽灵态描边提亮 `rgba(125,165,220,0.22)`；警示底/描边用 `withA(#F0524F, 0.12/0.5)`。mockup 帧⑧已验证对比度达标。

## 4. 隐藏/改名存储两案（需拍板）

- **案 a（端上视图态，S+）**：localStorage 存 hidden 键集+显示名覆盖。零 relay 改动、当班即做；代价=**跨端不同步**（桌面隐藏、手机仍见）+重装丢失。v3 原型本身是单设备演示语言，此案够用。
- **案 b（relay 存储，M）**：org/projects.json 组对象加 `display_name?/hidden?` 字段（组）+ 未立项桶隐藏需独立注册表（新文件 org/project-hidden.json，键=归一目录）。跨端同步、重启留存；代价=relay 读写面+SNAPSHOT 扩字段+CLI 管理命令。
- **建议**：案 a 先行（今晚量级），案 b 挂账等跨端需求实锤（用户双端都看板时再升）。

# 输出物·意图声明制说明（2026-09-19，#69）

> 口径权威在 `relay/src/session-manager.ts` 文件头注释，本文面向使用者解释双通道。

## 背景

#51 的扩展名白名单启发式（收 md/html、排代码）被否定：前端项目改一堆 HTML 会把输出 tab 刷成噪音；排除入口名（index.html）也堵不住。用户三轮澄清后拍板：**只收「明确让我输出、让我交付」的东西**。

## 双通道

### ① 原地登记（主力通道）

- 交付物写到它本该在的位置（项目 `docs/`、约定的输出目录等），**不搬动**。
- agent 交付完成后登记：`~/.cc-deck/bin/deliver <绝对路径>`（内部 POST `/api/deliver`，body `{path, cwd}`）。
- relay 只在看板记录：path / size / exists / 时间，条目 tools 标「登记」。
- 归因：cwd 双向前缀匹配 → 最近活跃会话（Bash 环境拿不到 CLAUDE_SESSION_ID，这是可得的最强归因；同仓库并行会话极端场景可能挂到隔壁卡，可接受）。
- 持久化 `data/deliverables.json`（上限 300）：登记动作不在 transcript 里，重启回放 / 转录轮转触发的整表替换（setArtifacts）都会挂回，不丢不双计。
- **边界**：端上看板只显示元数据，内容不经过 relay（不把项目任意文件变成可下载服务）。

### ② 产物目录（全局一次性产物）

- 写进 `~/.cc-deck/artifacts/`（`CCR_ARTIFACTS_DIR` 可覆盖）即视为交付声明，任意格式（含二进制）自动收录。
- 产物中心（`/api/artifacts` + `/artifacts/<file>`，token 鉴权）提供列表与内容服务——手机/网页/桌面可直接打开。文件名允许中文。
- 适用：ui-review 汇总页、跨项目日报等不属于任何项目的产物。

## 明确不收

- 项目目录里的任何改动（代码、配置、文档）——不经登记不看板。
- 启发式扩展名判断彻底废除。

## ② 项目域 IA 重设计提案（#90 手机半面）

**现状**：项目 Tab=OrgTabs 内两 tab 之一（团队/项目切换）+项目卡三行制+未立项折叠；项目详情无二级页。团队详情七节中④编制⑤活动与项目域数据有重叠面。

**V3 目标形态**（v8-ui-interactive-v3 L2438-2487）：项目 Tab=pcard 目录卡列表（自动识别+手动+已隐藏）→点卡进**项目详情二级页（只读聚合四分节：💬会话/👥团队/📦输出物/✅验收单，各带 jump「在 X 中查看」）**——联动不合并。

**去重建议表（六 tab/七节 vs 四大卡重叠面）**：

| 数据面 | 团队详情现有节 | V3 项目详情分节 | 建议去重 |
|---|---|---|---|
| 会话清单 | 无（成员会话=编制内） | 💬 会话（vrow+上下文%） | 不重叠——项目域新增 |
| 团队信息 | 页本体（头部+看板） | 👥 团队（团卡：N 成员·N 进行中） | **项目侧只放摘要卡+jump**（在 👥 中查看↗）——不复制看板 |
| 输出物 | 无 | 📦 输出物（类型 tag） | 项目域新增（SessionState.artifacts 聚合，relay 零改动） |
| 验收回流 | 无 | ✅ 验收单（三态行） | 项目域新增（acceptances 已随 SNAPSHOT） |
| 活动/回执流 | ⑤ 活动节 | 无对应 | **保留在团队详情**（组织语义）——项目详情不放（避免双入口双账） |
| 经验/铁律 | ⑥⑦ | 无对应 | 保留团队详情（组织资产） |
